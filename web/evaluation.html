How the tasks work

Every configuration gets the same starting layout and command rules. After that, observations report only what the last action did, so an agent has to keep track of state itself.

The last action and its outcome are shown to the reactive policy. The other configurations may receive additional history, model feedback, or graph facts.

Complex goals can need a key, washing, several objects, and closing a door or the tap. Success is checked against the simulator's real goal state.

Reference step counts are one feasible solution, not a proven minimum. Planning only runs after reflection rejects proposals, so it may never run.
