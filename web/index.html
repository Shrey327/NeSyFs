    Memo

    Local Qwen runs greedy, so an identical prompt always gives the same answer. Repeated reflection votes and identical planner particles reuse it instead of generating again.

    KV prefix cache

    Each task keeps a fixed instruction prefix, so the MLX server reuses its key/value cache and only prefills the new part. The bar above shows the share reused.

    Token caps

    Each task has its own output cap (128–384 tokens) and thinking is off, so a small model cannot ramble and heat the GPU.

    Honest trace

    You see model-written rationales, votes and outputs, not hidden reasoning. Planner particles are hypothetical and never written to the graph.
